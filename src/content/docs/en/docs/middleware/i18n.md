Internationalization (i18n) lets a Gin application serve content in multiple languages based on the user's preferences. This guide walks through wiring up [go-i18n](https://github.com/nicksnyder/go-i18n) with Gin, picking a language from the `Accept-Language` header, and falling back to a default locale.



## Installation



```bash

go get github.com/nicksnyder/go-i18n/v2/i18n

go get golang.org/x/text/language

go get github.com/pelletier/go-toml/v2

```



## Project layout



A minimal project keeps the translation files alongside `main.go`:



```text

.

├── main.go

└── locales

    ├── active.en.toml

    └── active.hi.toml

```



## Translation files



`locales/active.en.toml`



```toml

[Hello]

other = "Hello {{.Name}}!"

```



`locales/active.hi.toml`



```toml

[Hello]

other = "नमस्ते {{.Name}}!"

```



## Initialize the bundle



Create a bundle with a default language, register an unmarshaler for TOML, and load each translation file at startup. A new localizer is built per request from the `Accept-Language` header.



```go

package main



import (

  "github.com/gin-gonic/gin"

  "github.com/nicksnyder/go-i18n/v2/i18n"

  "github.com/pelletier/go-toml/v2"

  "golang.org/x/text/language"

)



func main() {

  bundle := i18n.NewBundle(language.English)

  bundle.RegisterUnmarshalFunc("toml", toml.Unmarshal)

  bundle.LoadMessageFile("locales/active.en.toml")

  bundle.LoadMessageFile("locales/active.hi.toml")



  r := gin.Default()



  r.GET("/hello", func(c *gin.Context) {

    lang := c.GetHeader("Accept-Language")

    localizer := i18n.NewLocalizer(bundle, lang)



    msg, _ := localizer.Localize(&i18n.LocalizeConfig{

      MessageID: "Hello",

      TemplateData: map[string]interface{}{

        "Name": "Raza",

      },

    })



    c.JSON(200, gin.H{"message": msg})

  })



  r.Run(":8080")

}

```



## Try it



```bash

# English

curl -H "Accept-Language: en" http://localhost:8080/hello

# => {"message":"Hello Raza!"}



# Hindi

curl -H "Accept-Language: hi" http://localhost:8080/hello

# => {"message":"नमस्ते Raza!"}

```



## Language fallback



When the requested language is unavailable, go-i18n automatically falls back to the bundle's default language -- in the example above, English.



## Pluralization



go-i18n supports CLDR plural rules. Define plural forms in the translation file:



```toml

[Items]

one = "{{.Count}} item"

other = "{{.Count}} items"

```



Then pass `PluralCount` when localizing:



```go

msg, _ := localizer.Localize(&i18n.LocalizeConfig{

  MessageID:   "Items",

  PluralCount: 5,

  TemplateData: map[string]interface{}{

    "Count": 5,

  },

})

// => "5 items"

```



## Best practices



- Store translations in TOML (or JSON/YAML) files separate from code.

- Use the `Accept-Language` header to select a locale for API responses.

- Keep message IDs stable -- treat them like API contracts.

- Prefer CLDR pluralization over manual string formatting.

- Load translation files once during application startup, not per request.

- Add a middleware that resolves the user's preferred language and stores it on the context.
