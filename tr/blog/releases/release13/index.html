DEĞİŞİKLİK GÜNLÜĞÜ

Bölüm başlığı “DEĞİŞİKLİK GÜNLÜĞÜ”
  • [YENİ] type map[string]string türünü sorgu dizesi veya form parametreleri olarak desteklemek için func (*Context) QueryMap, func (*Context) GetQueryMap, func (*Context) PostFormMap ve func (*Context) GetPostFormMap eklendi, bakınız #1383
  • [YENİ] func (*Context) AsciiJSON eklendi, bakınız #1358
  • [YENİ] http2 push desteği için type ResponseWriter içine Pusher() eklendi, bakınız #1273
  • [YENİ] Dinamik veri sunma için func (*Context) DataFromReader eklendi, bakınız #1304
  • [YENİ] Bağlamayı birden fazla kez çağırmaya izin veren func (*Context) ShouldBindBodyWith eklendi, bakınız #1341
  • [YENİ] Form bağlamada işaretçi desteği, bakınız #1336
  • [YENİ] func (*Context) JSONP eklendi, bakınız #1333
  • [YENİ] Form bağlamada varsayılan değer desteği, bakınız #1138
  • [YENİ] type StructValidator içinde doğrulayıcı motorunu dışa aktarma, bakınız #1277
  • [YENİ] func (*Context) ShouldBind, func (*Context) ShouldBindQuery ve func (*Context) ShouldBindJSON eklendi, bakınız #1047
  • [YENİ] Form bağlamada time.Time konumu desteği, bakınız #1117
  • [YENİ] func (*Context) BindQuery eklendi, bakınız #1029
  • [YENİ] jsonite build tag’leri ile isteğe bağlı yapıldı, bakınız #1026
  • [YENİ] Logger’da sorgu dizesi gösterme, bakınız #999
  • [YENİ] func (*Context) SecureJSON eklendi, bakınız #987 ve #993
  • [KALDIRILDI] func (*Context) GetCookie yerine func (*Context) Cookie
  • [DÜZELTİLDİ] func DisableConsoleColor çağrıldığında renk etiketleri gösterilmiyor, bakınız #1072
  • [DÜZELTİLDİ] func Mode çağrılırken Gin Mode "" artık const DebugMode döndürüyor, bakınız #1250
  • [DÜZELTİLDİ] Flush() artık responseWriter durum kodunu geçersiz kılmıyor, bakınız #1460
